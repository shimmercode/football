# اینفوگرافیک «خدمات طراحی سایت در ویرا»

| فایل | توضیح |
|---|---|
| **`vira-website-services.webp`** | خروجی نهایی وب — ۱۶۰۰×۱۸۸۰ (~۱۵۰ کیلوبایت) |
| `vira-website-services.png` | همان تصویر، PNG کیفیت کامل |
| `build_infographic.py` | اسکریپت ساخت |

## ساختار

- **هدر**: برچسب برند + تیتر + زیرعنوان (سه‌گانهٔ شرکتی/فروشگاهی/اختصاصی)
- **شبکهٔ ۳×۲ کارت** (چیدمان راست‌به‌چپ، شماره‌گذاری ۰۱ تا ۰۶):
  شرکتی و سازمانی، فروشگاهی، پزشکی، آموزشی، اختصاصی، بازطراحی
- هر کارت: نوار گرادیانی بالا، شماره، آیکون در دایرهٔ ملایم، عنوان،
  توضیح دو سطری، لینک «مشاهده جزئیات» (کارت ۰۵: «دریافت مشاوره»)
- **نوار CTA پایانی**: مشاوره رایگان + دکمهٔ «ثبت درخواست» + آدرس سایت

## هویت بصری

- رنگ برند `#450073`، گرادیان تا `#7A3FC4` و `#C79BFF`
- پس‌زمینهٔ لَوَندر روشن `#FAF8FD` با هالهٔ نرم
- آیکون‌ها از ست `icons/v2/webp/` (رنگ‌آمیزی مجدد با رنگ برند)
- فونت وزیرمتن؛ ارقام فارسی، و برای متن‌های حاوی لاتین
  (`B2B`، `Laravel`، `React`) نسخهٔ ارقام لاتین تا درست نمایش داده شوند

## ساخت مجدد

```bash
pip install pillow arabic_reshaper python-bidi
cd infographic && python3 build_infographic.py
```

متن‌ها و لینک‌ها در لیست `SERVICES` داخل اسکریپت قابل ویرایش‌اند.
حروف فارسی با `arabic_reshaper` + `python-bidi` به‌هم چسبیده و راست‌چین می‌شوند.
