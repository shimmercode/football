# راهنمای سبک بصری «ویرا» — Hero Mockup Style

مرجع: بنر «اعتبار برند شما در فضای دیجیتال»

این سند سبک را طوری ثبت می‌کند که بتوان هر بار همان لوکِ بصری را بازتولید کرد.

---

## ۱. آناتومی صحنه (Scene Anatomy)

```
┌───────────────────────────────────────────────┐
│                          ✳ 3D glossy shape    │  ← بالا/راست، پشت mockup
│   ┌──────────────┐                            │
│   │  device top  │   (تبلت/مانیتور، بدنه تیره) │
│   │              │                            │
│   └──────┬───────┘                            │
│  ▲ chrome│  long-scroll paper (curled)        │
│  cone    │  ادامه صفحه از دستگاه بیرون می‌ریزد │
│          ▼                    ✍ تایپوگرافی    │  ← پایین/راست
│      soft long shadow            فارسی        │
└───────────────────────────────────────────────┘
```

عناصر الزامی، به ترتیب اهمیت:

1. **Long-scroll mockup**: بخش بالای سایت داخل قاب دستگاه با بدنهٔ تیره؛ ادامهٔ صفحه به‌شکل یک ورق کاغذ بلندِ موج‌دار (curled / wavy paper) از پایین دستگاه بیرون می‌آید و در پرسپکتیو به سمت پایین-راست می‌رود. این امضای اصلی سبک است.
2. **یک شیپ ۳بعدی گلاسی** (اسپارکل/ستارهٔ چهارپر با گوشه‌های نرم) در بالا-راست، نیمه‌پنهان پشت mockup.
3. **یک شیپ ۳بعدی کرومی/فلزی** (مخروط) در چپ، کوچک‌تر، برای بالانس.
4. **سایهٔ نرم و بلند** زیر کاغذ.
5. **تایپوگرافی خوشنویسی فارسی** در پایین-راست، دو سطر با کنتراست رنگ و اندازه.

## ۲. ترکیب‌بندی

| ویژگی | مقدار |
|---|---|
| نسبت تصویر | ~ 1100 × 900 (تقریباً 5:4) |
| محور اصلی | قطری از بالا-چپ به پایین-راست |
| سهم mockup | ۶۰–۶۵٪ سطح، سمت چپ |
| سهم تایپوگرافی | پایین-راست، ۲۰٪ |
| Bleed | لبه‌های mockup عمداً از کادر بیرون می‌زنند |
| فضای منفی | زیاد؛ پس‌زمینهٔ خالیِ روشن، بدون بافت |
| زاویهٔ دید | ~ 8–12 درجه چرخش، پرسپکتیو ملایم |

## ۳. پالت رنگ

| نقش | نسخهٔ مرجع | نسخهٔ ویرا (برند بنفش) |
|---|---|---|
| پس‌زمینه | `#FFFFFF` | `#FFFFFF` یا `#FAF8FC` |
| اکسنت گرم (متن اصلی، دکمه‌ها) | `#F26522` | `#450073` |
| اکسنت مکمل (شیپ ۳بعدی) | `#4B57F5` → `#7C86FF` | `#7A3FC4` → `#B98BFF` یا نارنجی مکمل `#FF7A29` |
| بدنهٔ دستگاه | `#3A3A3C` | همان |
| متن ثانویه | `#1B2A4A` | `#221033` |
| سایه | مشکی با آلفای ۱۲–۱۸٪، بلور بالا | همان |

قانون: **یک رنگ گرم × یک رنگ سرد روی پس‌زمینهٔ سفید.** بیشتر از دو اکسنت وارد نکنید.

## ۴. متریال و نور

- نور نرم و پخش (soft studio light) از بالا-چپ.
- سه جنس متفاوت کنار هم — همین تنوع، حس «پریمیوم» می‌سازد:
  - **مات** → کاغذ
  - **گلاسی/شفاف** → شیپ رنگی ۳بعدی
  - **کرومی** → مخروط فلزی
- بدون بافت پس‌زمینه، بدون گرادیان پرزرق‌وبرق، بدون نویز.
- سایه‌ها بلند، کم‌کنتراست و بسیار بلور شده.

## ۵. تایپوگرافی

- خط اول: خوشنویسی مدرن فارسی (شکسته‌نستعلیقِ دیجیتال)، رنگ اکسنت گرم، بزرگ.
- خط دوم: همان خانواده با وزن/اندازهٔ کوچک‌تر، رنگ تیرهٔ خنثی.
- راست‌چین، با کشیدگی طبیعی، دقیقاً زیر خط اول و کمی جابه‌جا شده به چپ.
- بدون کادر، بدون سایهٔ متن.

## ۶. پرامپت پایه برای بازتولید

```
A premium clean website-showcase hero image on a pure white background.
A dark-bezel tablet at the top-left shows the hero section of a modern
website; the rest of the page continues out of the device as a long,
gently curled sheet of paper flowing diagonally toward the bottom-right,
with a soft blurred long shadow beneath it. A large glossy 3D four-point
sparkle shape in {ACCENT_COOL} floats behind the device at the top-right.
A small chrome metallic cone sits at the left edge. Soft diffused studio
lighting from the upper left, no background texture, lots of negative
space, muted realistic materials (matte paper, glossy plastic, polished
chrome). Brand accent color {ACCENT_WARM} used in the website's buttons
and highlights. Photorealistic 3D product mockup, marketing agency style.
```

جایگزین‌ها: `{ACCENT_WARM}` = `#450073` ، `{ACCENT_COOL}` = `#FF7A29` یا `#7A3FC4`

فضای خالی پایین-راست را برای افزودن تایپوگرافی فارسی خالی نگه دارید (متن فارسی را بعداً روی تصویر بگذارید، چون مدل‌های تصویری فارسی را درست نمی‌نویسند).

## ۷. چک‌لیست کیفیت

- [ ] پس‌زمینه کاملاً تمیز و روشن است؟
- [ ] کاغذ از دستگاه بیرون می‌ریزد و حالت موج طبیعی دارد؟
- [ ] فقط دو رنگ اکسنت در تصویر هست؟
- [ ] حداقل دو جنس متفاوت (مات + گلاسی/کرومی) دیده می‌شود؟
- [ ] سایه بلند و نرم است، نه سخت و تیره؟
- [ ] فضای خالی برای تایپوگرافی محفوظ مانده؟
- [ ] محور قطری حفظ شده؟

## ۸. نمونهٔ تست‌شده

`sample-hero-purple.png` خروجی واقعی همین پرامپت با رنگ برند بنفش است.
عناصر بازتولیدشده: تبلت با بدنهٔ تیره + کاغذ موج‌دار بلند + اسپارکل ۳بعدی گلاسی
+ مخروط کرومی + سایهٔ نرم + فضای خالی برای تایپوگرافی.

### نکاتی که در عمل مهم بود

- حتماً بنویسید «no text captions» وگرنه مدل متن لاتین بی‌معنی اضافه می‌کند.
- «Keep the bottom-right area empty white space» را نگه دارید تا جای متن فارسی بماند.
- اگر کاغذ زیادی صاف درآمد، به پرامپت اضافه کنید: "strong S-curve wave in the paper".
- برای بنر افقی از نسبت 16:9 و برای کارت خدمات از نسبت 4:5 استفاده کنید.
