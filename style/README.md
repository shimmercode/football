# بنر ویرا — «طراحی سایت حرفه‌ای در سال ۱۴۰۵»

طراحی اختصاصی ویرا؛ فقط از سبک مرجع الهام گرفته شده (کیفیت رندر سه‌بعدی،
فضای منفی زیاد، متریال گلاسی) — ترکیب‌بندی و عناصر کاملاً متفاوت است.

## خروجی نهایی

| فایل | توضیح |
|---|---|
| **`hero-vira-1405.webp`** | خروجی وب، ۱۹۲۰×۱۰۸۰ (~۱۱۵ کیلوبایت) |
| `hero-vira-1405.png` | همان بنر با کیفیت کامل |
| `hero2-base.png` | فقط رندر سه‌بعدی بدون متن — برای استفادهٔ مجدد |
| `compose_hero2.py` | اسکریپت چیدمان تایپوگرافی فارسی |

### تفاوت با تصویر مرجع

| مرجع | نسخهٔ ویرا |
|---|---|
| کاغذ موج‌دار از تبلت | پنل‌های شناور UI در پرسپکتیو ایزومتریک |
| اسپارکل + مخروط کرومی | ریبون سیال گرادیانی + کره‌ها و مکعب شیشه‌ای |
| نارنجی × آبی روی سفید | بنفش برند `#450073` × یاسی روی پس‌زمینهٔ لَوَندر روشن |
| متن خوشنویسی، بدون CTA | تیتر + پاراگراف + کارت تخفیف + دکمهٔ CTA |

## نگاشت با HTML

- `<h2>` → تیتر دو سطری، «۱۴۰۵» با هایلایت یاسی
- `<p>` → سه سطر توضیح
- `.monthly-offer` → کارت گرادیانی با نشان دایره‌ای «۲۰٪»
- مشاوره رایگان → دکمهٔ CTA پایین

## ویرایش و ساخت مجدد

```bash
pip install pillow arabic_reshaper python-bidi
cd style && python3 compose_hero2.py
```

متن‌ها داخل `compose_hero2.py` قابل تغییرند. حروف فارسی با
`arabic_reshaper` + `python-bidi` درست به هم می‌چسبند و راست‌چین می‌شوند.

## فایل‌های نسخهٔ قبلی

`hero-website-design-1405.*` و `compose_hero.py` مربوط به نسخهٔ اول
(نزدیک به تصویر مرجع) هستند و برای مقایسه نگه داشته شده‌اند.
`vira-hero-style.md` راهنمای سبک بصری است.
