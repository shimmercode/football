## ویرایش متن‌ها

متن‌ها داخل `compose_hero.py` هستند (تیتر، پاراگراف، کارت تخفیف، دکمه).
پس از تغییر:

```bash
pip install pillow arabic_reshaper python-bidi
cd style && python3 compose_hero.py
```

اسکریپت با `arabic_reshaper` + `python-bidi` حروف را درست به هم می‌چسباند و
راست‌چین می‌کند، پس متن فارسی همیشه صحیح رندر می‌شود.
